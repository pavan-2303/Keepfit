## Summary

Reconstruct Keepfit around a guided first run and five clear daily
destinations, with a compact query-only Coach and categorized Settings outside
the bottom navigation.

## Checklist

- [x] Resumable goal-and-constraint setup leads to an editable starter week.
- [x] Today, Plan, Log, Progress, and Coach are the primary destinations.
- [x] Settings is a categorized profile-level destination.
- [x] Today has one dominant next action and compact supporting information.
- [x] Coach supports normal questions and relevant local progression context.
- [x] Keepfit's local assistant daily cap and quota UI are removed.
- [x] Coach exposes no data-changing assistant actions.
- [x] Compact-width, large-font, offline, upgrade, and feature reachability are verified.

## Decisions and Deviations

| Date | Decision / Deviation | Reason |
|---|---|---|
| 2026-09-13 | Add Coach as the fifth primary destination | Conversation is a frequent workflow and the prior nested assistant was hard to discover and use. |
| 2026-09-13 | Remove Keepfit's local daily request cap | The user controls the OpenRouter account, credits, and provider plan. |
| 2026-09-13 | Coach is query-only in this version | Establish a clear, trustworthy read experience before exposing assistant mutations. |
| 2026-09-14 | Hide bottom-navigation text labels at 150% font scale and above while retaining icon content descriptions | Five labels cannot remain legible and unclipped at 360dp/200%; the labeled top bar and accessible descriptions preserve orientation and screen-reader use. |
| 2026-09-14 | Correct Coach Markdown in the active execution log rather than modifying the frozen version spec | The formatting defect was discovered during physical-phone review after implementation began; lifecycle rules place execution-time corrections here. |
| 2026-09-14 | Move broader review requests to a new approved backlog initiative | Recovery, profiles, catalogue replacement, pose sets, durable Coach memory, AI planning, and visual polish span several independent working increments. |
| 2026-09-14 | Render assistant Markdown with `multiplatform-markdown-renderer-m3` 0.41.0 and omit image-loading extensions | This removes raw formatting markers using native Compose, stays compatible with compile SDK 36, and does not introduce remote model-supplied media loading. |
