## Summary

Make active workouts faster and resilient with prior-value reuse, automatic
rest timing, safe in-session adaptations, optional completion feedback, and
transparent local progression.

## Checklist

- [x] Schema 8, migration, and backup preserve execution context and feedback.
- [x] Set append and repeat commands are ordered, transactional, and safe.
- [x] Previous-value and progression rules are deterministic and explained.
- [x] Active minimum and substitution changes protect logged work and plans.
- [x] Successful set logging starts the configured rest timer.
- [x] Active-workout UI reduces typing and covers completion feedback.
- [x] Active sessions restore after interruption without duplication.
- [x] App version and current documentation are updated.
- [x] Focused, broad, lint, build, connected, and manual verification pass.
