## Summary

Turn first-run setup into useful planning context and let Coach build a safe,
reviewable first plan even when the personal exercise catalogue is empty.

## Checklist

- [x] Assessment fields persist per profile with a tested Room migration.
- [x] Guided setup is focused, progressive, skippable where appropriate, and reviewable.
- [x] AI planning accepts an empty catalogue and validates new exercise definitions.
- [x] Applying a draft creates or reuses personal exercises transactionally.
- [x] Coach selection is hidden until OpenRouter is connected.
- [x] Documentation and automated/emulator verification are complete.

## Decisions and Deviations

| Date | Decision / Deviation | Reason |
|---|---|---|
| 2026-09-17 | Remove exercise-by-exercise avoidance and nutrition depth from first-run assessment | Activity, recovery, limitations, schedule, and equipment are more useful for the initial training plan |
| 2026-09-17 | Treat current build as optional context, not a scientific body-type classification | Avoids presenting somatotypes as medical or training facts |
| 2026-09-17 | Persist AI-created exercises only when the reviewed plan is applied | Keeps AI changes explicit and reversible before approval |
| 2026-09-18 | Do not collect gender in this increment | Neither the local nor AI request contract uses it; avoid sensitive data without product value |
| 2026-09-18 | Send baseline and assessment context only for explicit plan creation | Ordinary Coach questions retain the narrower context policy |
