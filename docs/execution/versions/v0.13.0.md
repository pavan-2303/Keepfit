## Progress Log

**2026-09-14** - Froze v0.13.0 from the approved initiative after v0.12.0
closed. Repository inspection confirmed that photos currently persist the
four-value `TransformationPhotoAngle` enum, the UI renders all four as equal
cards, and media import copies source bytes unchanged. Chose lowercase stable
pose keys in Room, a shared typed catalogue in `core:model`, and profile-owned
optional selections while retaining all four basic poses.

**2026-09-15** - Completed Room schema 12, migrated legacy angle values,
implemented profile-owned optional pose selections, guided incomplete capture,
strict same-pose comparison, neutral Compose reference figures, and optional
alignment lines. Photo imports now apply orientation, bound the longest edge to
2048 pixels, and remove source EXIF metadata through re-encoding.

**2026-09-15** - Verified 13 Room migration/DAO tests, 4 media tests, 4
transformation repository/UI tests, and 2 encrypted-backup tests. The combined
unit, lint, and debug assembly run passed 677 Gradle tasks. The APK upgraded an
existing v0.12.0 install to v0.13.0 and also passed a clean install and launch
without a fatal Android runtime crash.

## Decisions and Deviations

| 2026-09-14 | Normalize to the source format at a maximum 2048-pixel edge | This preserves supported file behavior while bounding storage and stripping metadata through re-encoding. |
