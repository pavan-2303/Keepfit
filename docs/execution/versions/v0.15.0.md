## Summary

Add original, rights-recorded, code-native movement guidance for 25 common
bundled exercises at the points where a person chooses and performs them.

## Checklist

- [x] Exactly 25 entries map to intended stable bundled exercise UUIDs.

## Progress Log

**2026-09-15** - Froze v0.15.0 with a 25-exercise pack drawn from the stable

## Decisions and Deviations

| Date | Decision / Deviation | Reason |
|---|---|---|
| 2026-09-15 | Use original Compose Canvas artwork rather than generated raster images | Code-native diagrams have clear provenance, scale across densities, keep the APK small, and are easier to make accessible. |
| 2026-09-15 | Limit the first pack to 25 representative exercises | This is large enough to cover common movement families while permitting careful form and rights review. |
| 2026-09-15 | Require user-triggered movement replay | Training screens should stay calm, and reduced-motion users must not receive an unavoidable loop. |
| 2026-09-15 | Keep unsupported exercises text-only | A generic or mismatched diagram would be less useful and potentially unsafe. |
| 2026-09-15 | Stack replay controls below the guide heading | The installed phone-width review showed that a horizontal header compressed the explanatory text. |
