## Summary

Replace the shallow first-run form with a progressive local intake and finish
with an honest choice between an offline starter week, manual planning, and the
existing query-only Coach.

## Progress Log

**2026-09-16** - Froze v0.16.0 around purposeful local inputs and three honest
planning exits. Excluded gender/calculation sex because it does not affect BMI
or the deterministic planner, and deferred structured AI plan creation to the
validated v0.18.0 workflow.

**2026-09-16** - Set the interaction direction as a compact fitness intake
notebook: one decision per screen, a visible completion trail, restrained
baseline context, and an anchored next action rather than large decorative
cards or a catalogue-sized control wall.

**2026-09-16** - Added a two-step local profile intake with optional birth
date, height, starting weight, live BMI context, and transactional creation of
the profile plus its first owned measurement. Existing profile editing now
supports birth date without forcing any optional value.

**2026-09-16** - Reworked training setup into seven compact steps, collapsed
the searchable movement-constraint catalogue by default, and added final exits
to the offline preview, manual Plan, and query-only Coach.

**2026-09-16** - Passed focused unit, Room, and Compose tests; the full JVM
suite, lint, assembly, Android 12 app suite, Android 16 database/workout suites,
installed visual review, version check, and offline launch. Closed the release
with an Android 16 Health Connect provider anomaly recorded as a non-v0.16
environment follow-up.
