## Summary

Make nutrition useful at the level of detail the user can sustain, with faster
reuse and no loss of existing history when that level changes.

## Checklist

- [x] Mode, flexibility, and check-ins persist with compatible defaults.
- [x] Migration and backup round trips preserve every new value.
- [x] Summaries expose only the selected depth and bounded target ranges.
- [x] Meal repeat and saved-meal expansion remain independent and deterministic.
- [x] All four modes are understandable and switch without data loss.
- [x] Meal-quality check-in takes two actions from Today.
- [x] Numeric modes provide faster food and meal reuse.
- [x] App reports version 0.6.0 and documentation matches shipped behavior.
- [x] Focused, broad, connected, and manual verification pass.
