## Summary

Add user-authorized OpenRouter access, secure local credentials, explicit
privacy boundaries, and a conservative daily request allowance while keeping
the local product independent from AI availability.

## Checklist

- [x] PKCE and callback behavior is deterministic and fail-closed.
- [x] Credentials and pending authorization are Keystore encrypted and excluded
  from backups, logs, DataStore, and build configuration.
- [x] Current-key inspection, disconnect, revoked, invalid, quota, and provider
  states are implemented.
- [x] Every inference request enforces ZDR and data-collection denial.
- [x] Ten-request local-day allowance is atomic and visible.
- [x] First-use disclosure and connection controls are understandable and
  preserve drafts on failure.
- [x] Existing assistant behavior runs only with a user-authorized credential.
- [x] App reports version 0.8.0 and documentation matches shipped behavior.
- [x] Focused, broad, device, APK, and backup checks pass.

## Decisions and Deviations

| Date | Decision | Reason |
|---|---|---|
| 2026-09-13 | Use OpenRouter's documented localhost callback in the private Android build | OpenRouter OAuth accepts HTTPS and localhost callbacks, not Android custom schemes; Keepfit has no owned public domain or backend |
| 2026-09-13 | Keep the named `inclusionai/ling-3.0-flash-sante:free` candidate | The model remains available and supports tool calls; predictable evaluation is preferable to the changing `openrouter/free` pool |
| 2026-09-13 | Exclude weight context entirely in this slice | It honors the approved default and avoids adding a sensitive toggle before bounded coaching workflows are evaluated |
| 2026-09-13 | Count an allowance request immediately before transport dispatch | Provider uncertainty must not create an automatic or invisible retry path |
| 2026-09-13 | Add a visible cancel action while browser authorization is pending | A user who returns without approving access should not wait for the callback timeout |

## Blockers

- Public distribution needs an owned HTTPS domain and hosted `assetlinks.json`
  before the localhost callback can be replaced by a verified Android App Link.
- Final account grant, revoke, and reconnect need the product owner's OpenRouter
  account on the physical phone; deterministic credential and error fixtures
  cover those transitions in automation.
- Formal structured coaching validation and the fixed model-quality evaluation
  set remain Slice H work.
