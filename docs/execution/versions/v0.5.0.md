## Summary

Create a calm offline weekly review and one explicit, editable decision for the
coming week without rewriting reusable plans or requiring AI.

## Checklist

- [x] Schema 9 and backup preserve idempotent review outcomes.
- [x] Review pause/resume persists as a local preference.
- [x] Window, evidence, motivation, and proposal rules are deterministic.
- [x] Preview and editing do not mutate plans or occurrences.
- [x] Approval creates one reviewed dated occurrence; dismissal creates none.
- [x] Today entry and focused review UI cover all required states.
- [x] App version and current documentation are updated.
- [x] Focused, broad, lint, build, connected, and manual verification pass.

## Decisions and Deviations

| Date | Decision / Deviation | Reason |
|---|---|---|
| 2026-09-12 | Apply approved changes as dated occurrences in the following ISO week | It makes one-week adjustments explicit while protecting reusable templates, recurring plans, history, and later weeks |
| 2026-09-12 | Use Room for structured review outcomes and DataStore only for pause | This follows the existing storage boundaries and prevents repeated weekly prompts |
| 2026-09-12 | Use a seven-day week ribbon as the review screen's signature visual | It shows plan, completion, and interruption in one compact, fitness-specific view |
