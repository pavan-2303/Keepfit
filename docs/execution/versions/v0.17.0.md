## Summary

Persist private profile-scoped Coach conversations, bound provider memory, and
let each new thread choose a named warm, direct, or analytical communication
style.

## Checklist

- [x] Room owns profile-scoped conversations, messages, and migration.
- [x] Threads survive restart, remain isolated, and participate in backup.
- [x] Mira, Rook, and Atlas have distinct prompts with common safety rules.
- [x] Provider context contains capped rolling memory plus 12 recent messages.
- [x] New, switch, rename, clear-memory, and delete flows are implemented.
- [x] Markdown, connection, privacy, compact-width, and large-text behavior
      remains sound.
- [x] Documentation, regression, install, restart, and APK checks pass.

## Progress Log

**2026-09-16** - Froze v0.17.0 around durable query-only conversations and
bounded memory. Structured AI plan creation remains reserved for v0.18.0.

**2026-09-16** - Chose a training-partnership visual direction. The existing
Keepfit palette remains authoritative: field green `#196B4A`, warm action
orange `#D9772B`, slate `#496456`, paper `#F7F8F3`, white, and ink `#18201B`.
Coach identity uses initials, one compact color accent, and a slim identity
strip rather than remote avatars, gradients, or a grid of oversized cards.
Typography stays with the existing deliberate sans hierarchy. Conversation is
left-aligned; user messages remain right-aligned. A quiet thread drawer owns
management actions so the transcript and composer remain the primary layout.

dashboard-style Coach card concept because it repeated generic equal-card UI

through names, one-sentence tone samples, stable prompt contracts, and small
identity marks.

**2026-09-16** - Added schema 14 with profile-owned conversation/message rows,

shared safety boundary.

**2026-09-16** - Reworked Coach around a compact identity header, scrollable

## Decisions and Deviations

| Date | Decision / Deviation | Reason |
|---|---|---|
| 2026-09-16 | Three built-in Coaches: Mira, Rook, and Atlas | Covers warm, direct, and analytical preferences without an unmaintainable persona catalogue. |
| 2026-09-16 | Keep the full local transcript but send only capped memory plus 12 recent messages | Preserves user history while controlling provider disclosure, latency, and cost. |
| 2026-09-16 | Clear memory does not delete the transcript | The action can change future AI context without destroying the person's local record. |
| 2026-09-16 | Use code-native initials instead of remote portraits | Keeps the feature offline-safe, private, fast, and rights-clear. |
