## Summary

Make exercise guidance useful offline and validate a strictly transient,
attributed animated online catalogue without weakening local-first behavior.

## Checklist

- [x] Forty owned guides are searchable offline with stable original keys.
- [x] Offline additions are explicit, editable, and duplicate-safe.
- [x] Source rights and media status are documented.
- [x] Provider contracts, adapter, mapping, and failures are deterministic and fakeable.
- [x] Remote results and GIFs are transient, cache-disabled, view-only, and attributed.
- [x] The three sources are visually and semantically distinct.
- [x] Existing local workout workflows remain complete without network access.
- [x] App reports version 0.7.0 and documentation matches shipped behavior.
- [x] Focused, broad, connected, privacy, and manual verification pass.

## Decisions and Deviations

| Date | Decision / Deviation | Reason |
|---|---|---|
| 2026-09-13 | Keep ExerciseDB results view-only and transient | Current caching and persistence rights are not explicit enough for durable storage or public release |
| 2026-09-13 | Use 40 original text guides without bundled media | This gives dependable offline value while avoiding unlicensed or low-confidence demonstrations |
| 2026-09-13 | Use a source-provenance rail as the signature interaction | Ownership, offline availability, and live privacy behavior must remain visible instead of being hidden in filters |
| 2026-09-13 | Keep Room schema 10 and the current backup manifest | Bundled definitions and remote display state are not authoritative persisted data |
| 2026-09-13 | Pin Coil 3.4.0 | Newer releases require SDK/Kotlin metadata beyond the project's compile SDK 36 and current Hilt processor |
| 2026-09-13 | Treat a GIF CDN 504 as a recoverable provider-media failure | The catalogue and instructions remained available; the provider controls live media availability |
