# Progress

## Measurements

Open `Progress` to log body measurements over time.

You can record:

- weight;
- waist;
- chest;
- hips;
- left and right arm;
- left and right thigh;
- notes.

BMI is derived from your saved height and latest weight.

## Transformation Cycles

Keepfit organizes transformation photos into cycles. The first uploaded batch
starts a cycle. Each cycle day can include these angles:

- front
- left
- right
- back

Uploading the same angle twice on the same day replaces the previous photo for
that day. Photos are imported into app-private storage.

## Compare Cycle Days

Use the `Compare` area to select two cycle days and one angle. By default,
Keepfit shows day 0 and the latest updated day from the current cycle.

This is useful for:

- checking visual change over time;
- comparing the same pose across different cycle days;
- spotting changes that scale readings alone may not show.

If a photo is missing for one of the selected days, Keepfit shows an empty
state instead of blocking the rest of the comparison.

## Cycle Notes

Use cycle notes to store brief context such as:

- travel stretch;
- cut or bulk phase;
- low-energy block;
- recovery notes.

## Closing and Reopening

- Use `Close cycle` when you want to move the current cycle into history.
- A closed cycle can be reopened only if no newer cycle has started.
- If there is no active cycle, importing a photo starts a new one on the
  selected day.

## Good Practices

- Take photos in similar lighting and clothing when possible.
- Use the same angle and distance on each check-in day.
- Log weight and measurements regularly enough for trends to matter.
- Keep day 0 consistent because it anchors later comparison.
