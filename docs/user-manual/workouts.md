# Workouts

## Exercise Library

Open `Workouts` and use the `Exercises` tab to build your personal library.

You can:

- add a new exercise;
- edit name, muscle group, instructions, and notes;
- mark an exercise as bodyweight-based;
- attach optional private demo media from the device;
- archive exercises you no longer want to use often.

Archiving does not remove past workout history.

## Templates

Use the `Templates` tab to create reusable workouts.

Each template can include:

- an ordered list of exercises;
- target sets and reps;
- template-level notes.

Templates are reused in the weekly plan and in workout history.

## Weekly Plan

Use the `Plan` tab to assign templates to weekdays.

Typical flow:

1. Create one or more templates.
2. Open `Plan`.
3. Assign each template to the weekdays you want.
4. Return to `Today` to start the planned workout.

## Start and Complete a Workout

From `Today`, tap `Start workout` when a workout is planned.

During an active workout you can:

- add sets;
- enter reps and weight;
- save exercise notes;
- view previous values for context;
- start the rest timer.

When the workout is finished, complete the session to move it into history.

## History and Records

Use the `History` tab to review completed sessions and simple personal records.

Historical logs stay readable even if the related exercise is archived later.

## Practical Advice

- Create simple templates first. You can refine them later.
- Use exercise notes for form cues or machine settings.
- Keep exercise names stable so history remains easy to scan.
