# Version Spec - v0.15.0 - Owned Core Exercise Guidance

> **Linked initiative:** [Durable Personalized Fitness Companion](../backlog/items/durable-personalized-fitness-companion.md)
> **Status:** Approved and frozen for execution
> **Estimated effort:** 8-12d
> **Risk:** Medium
> **Prerequisites:** [v0.14.0 complete](../done/versions/v0.14.0.md)

---

## Sprint Goal

Give the most common bundled exercises clear, lightweight visual movement
guidance without importing third-party imagery, requiring a network, or making
the full catalogue and APK impractically large.

## Delivered Increment

Twenty-five prioritized bundled exercises receive an original Keepfit movement
card with a scalable body diagram, start and finish states, a user-triggered
motion preview, one primary form cue, and a concise safety cue. Guides are
available from both exercise details and an active workout, work fully offline,
and remain optional beside the existing English instructions.

## Work Items

### Item 1 - Rights-aware core guidance registry

**Why**

Every visual must map to a stable catalogue exercise and carry reviewable
ownership information before it can enter the application.

**What to do**

1. Define an immutable registry for 25 stable v0.14 catalogue UUIDs across
   squat, hinge, push, pull, single-leg, isolation, and core movements.
2. Record movement pattern, view, form cue, safety cue, artwork family,
   authorship, rights basis, and review date for every entry.
3. Add executable validation for unique IDs, complete rights fields, catalogue
   membership, supported movement patterns, and exact inventory count.

**Affected files or subsystems**

- `core:media` guidance models and registry
- `tools/media` guidance-pack verification
- exercise guidance rights register

**Dependencies**

- Stable bundled exercise UUIDs from v0.14.0

**Estimated effort**

- 2d

**Done when**

- [ ] Exactly 25 guidance entries resolve to the intended bundled exercises.
- [ ] Every entry has complete original-artwork provenance and review metadata.
- [ ] Verification rejects unknown exercises, duplicate mappings, incomplete
      rights data, and unsupported visual patterns.

### Item 2 - Original scalable movement renderer

**Why**

Large GIF or video packs would inflate the APK, and third-party assets would
reintroduce the licensing uncertainty v0.14 removed.

**What to do**

1. Draw a consistent original body-and-equipment diagram with Compose Canvas
   from normalized start and finish joint positions.
2. Support the registry's movement patterns and views through reusable pose
   definitions rather than copied exercise-specific bitmap files.
3. Provide a user-triggered replay that respects disabled system animations,
   plus a meaningful static and screen-reader description.

**Affected files or subsystems**

- `feature:workouts` Compose guidance UI
- `core:media` pose metadata

**Dependencies**

- Item 1

**Estimated effort**

- 3d

**Done when**

- [ ] Each supported exercise shows legible start and finish movement states.
- [ ] Motion starts only after the user requests it and remains understandable
      when animation is disabled.
- [ ] The renderer uses no downloaded, generated, or third-party visual file.

### Item 3 - Guidance at the decision point

**Why**

Guidance is most useful while choosing an exercise or preparing to log its next
set, not in a disconnected media browser.

**What to do**

1. Add the movement card near the top of supported bundled exercise details.
2. Add a compact `View guide` action to supported exercises in an active
   workout and open the same guidance without losing session state.
3. Keep unsupported exercises text-first and preserve private user-attached
   GIF and video behavior without implying those files are Keepfit-owned.

**Affected files or subsystems**

- exercise detail UI
- active workout UI
- Compose tests

**Dependencies**

- Items 1-2

**Estimated effort**

- 2d

**Done when**

- [ ] Supported exercise details show a guide without displacing essential
      metadata and instructions.
- [ ] A guide can be opened and closed during a workout without changing sets,
      notes, timer, substitutions, or workout state.
- [ ] Unsupported and user-created exercises retain their current text/private
      media experience without an empty guidance placeholder.

### Item 4 - Distribution, performance, and user guidance

**Why**

The pack is useful only if ownership is transparent and it does not compromise
offline startup, scrolling, accessibility, or APK size.

**What to do**

1. Extend Settings and repository notices with the original guidance family,
   pack inventory, and the distinction from upstream Gym media.
2. Update architecture, workout guidance, version metadata, and the APK-size
   baseline.
3. Verify offline use, animation-disabled behavior, compact-width layout,
   active-workout continuity, build, lint, device tests, and installation.

**Affected files or subsystems**

- `feature:settings`
- project and user documentation
- Android version metadata and APK

**Dependencies**

- Items 1-3

**Estimated effort**

- 2d

**Done when**

- [ ] In-app and repository notices identify the guides as original Keepfit
      code-native artwork and continue to exclude upstream Gym media.
- [ ] The 25-guide pack works in airplane mode and adds no runtime provider.
- [ ] Tests, lint, debug assembly, install, launch, accessibility checks, and
      APK-size comparison pass.
