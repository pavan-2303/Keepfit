# Version Spec - v0.23.0 - Personal Exercise Building

> **Linked initiative:** [User-Owned Exercise Catalogue](../backlog/items/user-owned-exercise-catalogue.md)
> **Status:** In progress - frozen 2026-09-17
> **Estimated effort:** 8-12d
> **Risk:** High
> **Prerequisites:** v0.22.0

---

## Sprint Goal

Make exercises and templates genuinely user-owned, progressive, and connected
throughout planning.

## Delivered Increment

New installations open with an empty personal exercise catalogue. Upgrades
remove untouched bundled records without breaking edited exercises, private
media, templates, plans, or history. A complete exercise form uses multiline
controls for guidance, templates start with a name, empty templates remain
editable but unschedulable, and exercise details open from both template and
weekly-plan paths.

## Work Items

### Item 1 - Retire the preloaded catalogue safely

**Why**

The bundled dataset adds volume without providing a catalogue the owner wants
to maintain.

**What to do**

1. Remove the bundled asset and startup seeding callback.
2. Add a Room migration that deletes untouched bundled rows and converts
   edited, referenced, or media-backed rows into personal exercises.
3. Remove obsolete attribution surfaces and keep backup/migration behavior
   compatible.

**Affected files or subsystems**

- `core:database`
- Catalogue tests, notices, README, architecture, and settings disclosures

**Dependencies**

- Existing Room foreign-key and archive rules

**Estimated effort**

- 3-4d

**Done when**

- [ ] Fresh installs contain zero preloaded exercises.
- [ ] Upgrade cleanup preserves all user edits, media, references, and history.

### Item 2 - Complete the exercise editor

**Why**

Important exercise metadata is currently hidden and long-form content is
presented like a short input.

**What to do**

1. Expose name, body area, equipment, primary target, secondary targets,
   instructions, notes, bodyweight state, and private demo attachment.
2. Use multiline text areas for instructions and notes and concise controls for
   identity and classification fields.
3. Persist edits to every visible field and keep validation actionable.

**Affected files or subsystems**

- `feature:workouts` input model, validation, repository, ViewModel, and UI

**Dependencies**

- Existing exercise columns and private media store

**Estimated effort**

- 2-3d

**Done when**

- [ ] Every supported exercise field can be added and edited.
- [ ] Long instructions and notes render as usable multiline controls.

### Item 3 - Progressive templates and connected details

**Why**

Template creation and exercise inspection should follow the way plans are
actually maintained.

**What to do**

1. Create templates from a name only and add exercises inside template details.
2. Allow the last exercise to be removed; unschedule a template when it becomes
   empty and reject assigning an empty template.
3. Open exercise details from template rows and scheduled-plan details.

**Affected files or subsystems**

- `feature:workouts` repository and Compose UI
- `core:database` workout DAO transaction

**Dependencies**

- v0.22.0 direct template maintenance

**Estimated effort**

- 3-5d

**Done when**

- [ ] A name-only template can be created and then populated from its detail page.
- [ ] Empty templates remain editable but cannot create an empty planned workout.
- [ ] Exercise details are reachable from templates and the weekly plan.

## Testing Requirements

- [ ] Migration and fresh-database tests cover catalogue removal and preservation.
- [ ] Repository tests cover empty template creation, final removal, and schedule safety.
- [ ] Compose tests cover the complete exercise form and both detail-navigation paths.
- [ ] Unit tests, instrumentation tests, lint, builds, and emulator verification pass.

## Definition of Done

- [ ] Every work-item checklist is complete.
- [ ] The delivered increment is usable, not placeholder-only.
- [ ] Required tests and verification steps pass.
- [ ] Follow-up work is captured separately rather than left implicit.
