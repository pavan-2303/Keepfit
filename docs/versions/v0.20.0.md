# Version Spec - v0.20.0 - Exercise Clarity and Licence Boundaries

> **Linked initiative:** [Open-source Release and Content Stewardship](../backlog/items/open-source-release-and-content-stewardship.md)
> **Status:** In progress - frozen 2026-09-16
> **Estimated effort:** 5-8d
> **Risk:** Medium
> **Prerequisites:** v0.19.0

---

## Sprint Goal

Make exercise details useful at a glance while establishing honest, compact
licence boundaries for the code, upstream catalogue, and future original media.

## Delivered Increment

A user opens an exercise into a structured movement sheet with compact facts,
numbered technique steps, media or movement guidance, and clear actions. The
catalogue's repeated MIT source line is removed from exercise content, while a
single compact About disclosure and packaged licence preserve attribution.

## Work Items

### Item 1 - Consolidate licensing and notices

**Why**

README-only attribution does not accompany every installed APK, while a legal
line on every exercise wastes the space needed for useful guidance.

**What to do**

1. License Keepfit source code under Apache-2.0.
2. Document that only explicitly identified media is restricted and that user
   imports retain their owner's rights.
3. Keep the upstream MIT terms in repository and packaged assets and expose
   one compact in-app open-source notice.

**Affected files or subsystems**

- Repository licence and notice files
- Catalogue packaged assets
- Settings About UI

**Dependencies**

- Pinned v0.14.0 catalogue rights register

**Estimated effort**

- 2d

**Done when**

- [ ] Code, restricted media, user media, and third-party content boundaries are explicit.
- [ ] Full upstream terms remain packaged in the APK.
- [ ] No exercise detail repeats catalogue copyright or MIT text.

### Item 2 - Rebuild exercise details as a movement sheet

**Why**

The current dialog renders metadata, instructions, notes, and attribution as a
single text stream that is hard to scan between sets.

**What to do**

1. Add a strong header and source-neutral exercise type label.
2. Group body area, equipment, target, and secondary muscles into a compact
   movement profile.
3. Render instructions as numbered technique steps and notes as a distinct
   section, keeping movement media prominent and actions stable.

**Affected files or subsystems**

- `feature:workouts` exercise catalogue UI
- Workout Compose instrumentation tests

**Dependencies**

- Existing v0.15.0 movement guide

**Estimated effort**

- 3-6d

**Done when**

- [ ] Details remain usable at compact width and 200% text.
- [ ] Empty instructions have a helpful fallback.
- [ ] Existing original movement guidance and private media still work.
