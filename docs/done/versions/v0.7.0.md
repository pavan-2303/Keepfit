## Summary

Keepfit now has a useful exercise guide before a user creates anything: 40
original guides work fully offline, selected guides can be added safely to the
private editable library, and an optional ExerciseDB prototype provides
attributed live search and animation attempts without persisting remote data.

## Changelog

- Added a source-provenance rail separating the private library, owned offline
  guidance, and view-only live demonstrations.
- Expanded the deterministic starter catalogue from 16 to 40 original exercise
  definitions while preserving the original keys and order.
- Added offline name, movement, instruction, and equipment filtering plus an
  explicit, case-insensitive duplicate-safe add-to-library flow.
- Added provider-independent catalogue contracts and a keyless ExerciseDB V1
  adapter with bounded timeouts, strict mapping, trusted media URLs, and clear
  offline, timeout, malformed, and provider failure states.
- Added cache-disabled GIF loading, attributed written-step fallbacks, and
  private GIF or video playback for user-imported exercise media.
- Kept Room at schema 10 and the backup manifest unchanged because all remote
  catalogue state is transient and the offline catalogue is code content.
- Updated the application to version `0.7.0` with version code `7`.

## Product Increment Delivered

A user can understand the origin and privacy behavior of every exercise source,
find useful guidance without a connection, add owned guidance to their personal
library without accidental duplicates, and deliberately search a live provider
for attributed demonstrations. Provider failure never blocks local exercise
creation, planning, workout execution, or written offline guidance.
