## Summary

Keepfit now turns the active recurring week into one decisive local Today
action. A user can start or resume immediately, or review a date-specific
shorter, minimum, substitution, reschedule, skip, or restore decision without
rewriting templates or history.

## Changelog

- Added deterministic Today state precedence for active, completed, dated,
  recurring, missed, and rest-day states.
- Added review-before-confirm flows for shorter, minimum, substitution,
  reschedule, skip, restore, and missed-workout recovery decisions.
- Added dated workout-occurrence and exercise-snapshot storage in Room schema 7.
- Linked new workout sessions to occurrence snapshots while retaining legacy
  planned-workout history.
- Added encrypted backup preview and restore coverage for occurrence records.
- Made the workout action the visually dominant Today card while preserving the
  current Keepfit color and navigation language.
- Updated the application version to `0.3.0` with version code `3`.

## Product Increment Delivered

A returning user can understand the next workout action from Today, adapt one
date without damaging the weekly plan, recover the most recent unresolved
workout from the prior seven days, and continue using all of it offline.
