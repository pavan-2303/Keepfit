## Summary

Keepfit now starts with an empty personal exercise catalogue. People can record
complete exercise details, create a template from only its name, add or remove
exercises from inside it, and inspect exercise details from templates or the
weekly plan.

## Changelog

- Removed the packaged 1,316-record dataset, startup seeder, import ledger, and
  dataset-specific in-app notice.
- Added Room schema 15 and a migration that removes untouched seed rows while
  converting edited, referenced, archived, or media-backed rows into personal
  exercises.
- Exposed equipment, primary and secondary targets, multiline instructions,
  multiline notes, bodyweight state, and private demo attachment in the editor.
- Made template creation name-only and allowed empty templates to remain
  editable while preventing them from being scheduled.
- Clearing the final template exercise now removes future assignments in the
  same transaction without rewriting history.
- Added exercise details from template rows and scheduled-plan workout details.
- Kept AI plan creation compatible through privacy-safe aliases over the
  personal catalogue.

## Data and Compatibility Notes

- Existing personal exercises are unchanged.
- A retired catalogue row is preserved if its timestamp shows an edit, it is
  archived, it has private media, or any template/history table references it.
- Preserved legacy rows have `source` and `sourceId` cleared and behave as
  personal exercises after migration.
- Accepted starter plans may create the small set of exercises they use; this
  is explicit user action rather than preloading a browseable catalogue.
