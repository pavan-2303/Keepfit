## Summary

Keepfit now gathers planning-relevant activity, recovery, routine, schedule,
equipment, and limitation context in a focused, skippable assessment. Coach
selection follows OpenRouter connection, and a reviewed AI plan can create the
personal exercises it needs even when the catalogue starts empty.

## Changelog

- Expanded the profile-owned journey record with activity level, sleep duration
  and schedule, current build, routine challenges, limitation areas, and notes.
- Reworked setup into nine single-theme steps with progress, a final review,
  and an immediate skip route to offline, manual, or Coach planning.
- Included bounded baseline and assessment context only in an explicit AI plan
  request; ordinary chat retains its narrower privacy boundary.
- Extended the strict AI tool contract to accept either known short-lived
  exercise aliases or complete new exercise definitions.
- Marked proposed definitions in plan review and created or reused them only
  when the person approves the complete plan.
- Kept plan, template, target, and new-exercise writes in one Room transaction.
- Moved the Coach picker behind the OpenRouter connected state.
- Added Room schema 16 and a tested 15-to-16 migration with conservative
  defaults for existing profiles.

## Product and Privacy Decisions

| Decision | Reason |
|---|---|
| Do not add gender to the current assessment | The implemented planner does not use it, so collecting another sensitive attribute would add no visible value |
| Treat current build as optional self-description | It is context, not a medical classification or fixed somatotype |
| Send baseline and assessment fields only for explicit plan creation | General Coach questions do not need those sensitive inputs |
| Save AI-created exercises only with approved plans | Preview, invalid output, dismissal, and storage failure must leave the catalogue unchanged |

Fitify informed the categories, not Keepfit's layout, wording, or planning
logic. Public reference material described goal, experience, available time,
equipment, fitness level, and basic profile personalization; a reliable public
step-by-step copy of its current onboarding was not available.
