## Summary

Keepfit now lets each user choose the amount of nutrition tracking they can
sustain: detailed macros, calories and protein, meal-quality check-ins, or no
nutrition tracking. Every mode remains local, preserves existing history, and
feeds Today and the weekly review at the selected level of detail.

## Changelog

- Added four persistent nutrition depths and 5%, 10%, or 15% goal ranges, with
  existing installations defaulting compatibly to detailed macros and 10%.
- Added Room schema 10 for one replaceable meal-quality check-in per date and
  meal, with migration, exported schema, DAO, repository, and backup coverage.
- Added a prominent nutrition-lens selector, mode-specific summaries, a
  two-action meal-quality flow, and a history-safe disabled state.
- Added serving presets, scoped repeat-yesterday meal actions, and independent
  saved-meal expansion for faster numeric logging.
- Made Today and weekly-review nutrition evidence respect the selected depth;
  disabled nutrition contributes no review signal.
- Updated the application to version `0.6.0` with version code `6`.

## Product Increment Delivered

A user can select the least burdensome nutrition workflow that still helps
them, log or check in from Today, reuse yesterday's relevant meal without
overwriting the rest of the day, and change modes later without losing diary or
meal-quality history.
