## Summary

Keepfit now includes original, code-native movement guidance for 25 common
exercises in its bundled offline catalogue. Each supported exercise has a
static start/finish diagram, an explicit replay control, a concise movement cue,
and a safety cue in both exercise details and active workouts. Unsupported
exercises remain text-only rather than receiving a potentially misleading
generic diagram.

## Changelog

- Added a rights-recorded registry mapping exactly 25 stable bundled exercise
  UUIDs and source identifiers to reviewed movement, equipment, and target
  patterns.
- Added normalized start and finish poses with clamped interpolation for 22
  reusable movement patterns.
- Added an original Compose Canvas renderer with equipment context, target
  emphasis, start/finish meaning, and user-triggered replay.
- Added the same movement card to exercise details and a focused guide dialog
  during active workouts without changing set or session state.
- Added practical form and safety cues plus an explicit original-artwork label.
- Kept unsupported exercises and user-imported private demonstrations on their
  existing text/private-media paths.
- Added an executable verifier for entry count, stable catalogue identity,
  rights declarations, and accidental visual-file inclusion.
- Updated Settings, architecture, user guidance, and the rights register to
  distinguish Keepfit artwork from the excluded dataset Gym media.
- Updated the Android app to version `0.15.0` with version code `15`.

## Product Increment Delivered

A person can learn or quickly recall 25 common movements without connectivity,
leaving an active workout, or trusting externally hosted imagery. The quiet
static card communicates both positions immediately; motion plays only after a
deliberate tap and remains nonessential to understanding the guide.

## Deviations from Original Plan

| Item | Planned | Actual | Reason |
|---|---|---|---|
| Guidance medium | Original or separately licensed lightweight media | Original Compose Canvas figures | This provides clear provenance, density-independent rendering, small incremental size, and no bundled third-party media. |
| Card header | Compact horizontal heading and replay action | Stacked heading, explanation, and replay action | Installed phone-width inspection showed that the horizontal layout compressed the explanatory copy. |
| Animation | User-triggered movement preview | One forward-and-return replay with persistent static start/finish meaning | This keeps motion optional and the training screen calm. |
