## Summary

Keepfit now guides first run into an editable starter week and organizes daily
use around Today, Plan, Log, Progress, and a dedicated query-only Coach.
Settings is categorized behind the profile action, Today presents one dominant
next action, and Coach can answer general questions or deliberately use compact
local progress context without exposing data-changing actions.

## Changelog

- Added resumable, progressive goal-and-constraint setup with an editable
  offline starter week.
- Reorganized the primary shell into five journey-oriented destinations and
  moved categorized Settings out of bottom navigation.
- Simplified Today to one primary workout or recovery action with compact
  supporting nutrition, steps, review, and motivation information.
- Replaced the proposal-first assistant screen with a familiar query-only Coach
  timeline, compact connection state, and question-sensitive local context.
- Removed Keepfit's local assistant request cap and quota-progress UI.
- Added native safe Markdown presentation for assistant replies without an
  HTML surface or a remote-image loader.
- Hardened compact-width, 200% font-scale, offline, upgrade, and backup paths.
- Updated the app to version `0.10.0` with version code `10`.

## Product Increment Delivered

A new user can describe a realistic routine, review an offline starter week,
and enter a clear daily workspace. A returning user can act from Today, manage
the plan, log activity and nutrition, inspect progress, or hold a readable
Coach conversation without navigating through an oversized Settings or access
panel. Existing local tracking remains usable without AI or a network.
