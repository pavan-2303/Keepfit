## Summary

Keepfit now presents one compact header per primary destination, makes the
weekly schedule and nutrition diary lead their sections, and keeps secondary
libraries behind clear navigation. Coach history and composer state now match
the user's explicit actions.

## Changelog

- Removed duplicate headings, nested safe-area gaps, and primary tab strips.
- Added navigable Plan and Log tools plus template detail and edit flows.
- Preserved template identity, assignments, and retained exercise targets when
  editing through the offline catalogue.
- Delayed Coach conversation creation until the first question is sent.
- Cleared the Coach composer on send and retained failed payloads behind a
  separate retry action.

## Product Increment Delivered

A person can open Plan or Log and see the main task first, navigate to support
tools without peer tabs, inspect and edit reusable templates, and choose a
Coach without creating an empty conversation. Primary screens use the same
compact visual hierarchy and no longer double-apply system insets.
