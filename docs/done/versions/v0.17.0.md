## Summary

Coach conversations are now private, durable, and owned by the active local
profile. A person can choose Mira, Rook, or Atlas, keep multiple threads,
return after restart, and manage future provider memory without losing the
local transcript.

## Changelog

- Added schema 14 conversation and message records with cascade ownership and
  profile-filtered operations.
- Persisted completed turns atomically and kept provider context to a capped
  memory summary plus 12 recent messages.
- Added three named communication styles with distinct prompts and one shared
  safety boundary.
- Added new, switch, rename, clear-memory, and delete conversation flows.
- Preserved Markdown rendering, compact connection controls, privacy
  disclosure, compact-width usability, and large-text access.
- Included conversation data in supported database backup and restore while
  continuing to exclude secrets.

## Product Increment Delivered

Coach now behaves like an ongoing local training relationship instead of a
temporary generic chat. Conversations remain isolated when profiles change,
and only a bounded, disclosed subset is sent when the user asks OpenRouter a
question.
