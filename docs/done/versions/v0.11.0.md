## Summary

Keepfit now participates in device-dependent Android recovery with a strict
allowlist containing only its Room database and non-secret DataStore settings.
Private photos, imported exercise media, assistant drafts, OAuth state, and
credentials remain excluded. Missing media is safe, encrypted export remains
the complete recovery path, and supported devices offer separate opt-in,
validated OpenRouter token recovery through Google Block Store.

## Changelog

- Enabled Android cloud/device-transfer backup through exact modern and legacy
  allowlists.
- Added honest recovery guidance and recoverable missing-media presentation.
- Added disabled-by-default Block Store token recovery with validation,
  opt-out, disconnect cleanup, and reconnect fallbacks.
- Corrected root media ignore rules so the existing `core/media` source module
  is versioned while local user media remains ignored.
- Updated the app to version `0.11.0` with version code `11`.

## Product Increment Delivered

Structured fitness records and ordinary settings can participate in supported
Android reinstall/device-transfer recovery without placing private media or
secrets in that channel. Users retain a complete encrypted export option and
may independently choose whether a supported Google service can recover their
OpenRouter access.
