## Summary

Transformation tracking now stays quick with four required relaxed views and
can expand to any of eleven additional profile-specific poses. Existing photos
migrate to stable pose keys, incomplete check-ins remain valid, comparisons
stay pose-matched, and imported files are normalized for private, bounded local
storage.

## Changelog

- Added a shared 15-pose catalogue with stable lowercase keys, groups, labels,
  and concise positioning guidance.
- Added Room schema 12 with profile-owned optional pose preferences and a
  migration from the four legacy angle values.
- Added a selectable pose dialog while keeping front, right-side, back, and
  left-side relaxed poses permanently enabled.
- Added captured/enabled progress, neutral Compose reference figures, optional
  alignment lines, and explicit missing-counterpart comparison states.
- Normalized imported JPEG, PNG, and WebP photos by applying source
  orientation, limiting the longest edge to 2048 pixels, and stripping source
  EXIF metadata through re-encoding.
- Extended encrypted-backup verification to cover pose preferences and private
  transformation media without changing the existing archive contract.
- Updated the app to version `0.13.0` with version code `13`.

## Product Increment Delivered

A profile can use the four basic transformation photos for a fast check-in or
select detailed standard and flexed views when useful. Photos can be added
gradually, compared only against the same pose on another date, and recovered
through the explicit encrypted backup path.
