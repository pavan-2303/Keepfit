## Summary

Keepfit now ships 1,316 audited exercises as a deterministic bundled asset and
installs them into its authoritative Room database on first open. The complete
library, metadata search, and English instructions work without a network or
runtime catalogue provider, while user-created exercises and private media
continue to share the same practical workflow.

## Changelog

- Added a pinned, reproducible importer and verifier for
  `hasaneyldrm/exercises-dataset` revision
  `7455efae41b330c265e7cd4b78dfa848e7ce5ebd`.
- Normalized 1,324 source rows into 1,316 canonical records after resolving
  eight normalized duplicate groups.
- Added stable UUIDs, source provenance, equipment, target muscle, secondary
  muscles, and numbered English instructions without bundling Gym visual media.
- Added Room schema 13, its migration, a catalogue-import ledger, and
  transactional idempotent seeding that preserves existing local records.
- Rebuilt the exercise library as one lazy, locally searchable Room-backed
  catalogue for bundled and user-created exercises.
- Removed the runtime ExerciseDB provider and its network-specific dependency.
- Added source and licence disclosure in exercise details and Settings.
- Preserved catalogue metadata and import state through encrypted backup and
  restore.
- Updated the Android app to version `0.14.0` with version code `14`.

## Product Increment Delivered

A fresh installation can browse, search, inspect, and use a large exercise
library immediately in airplane mode. Existing installations gain the same
catalogue without replacing user-created exercises, and normal workout,
template, private-media, and backup workflows continue to operate on stable
Room identifiers.

## Deviations from Original Plan

| Item | Planned | Actual | Reason |
|---|---|---|---|
| Accepted count | Initial audit estimated 1,317 | 1,316 | Executable punctuation normalization found an eighth duplicate group. |
| Catalogue installation | Seed on creation or first open | Seed on each open only when the pinned import ledger is absent | This supports both fresh databases and upgrades while remaining idempotent. |
| Guidance media | Text-first catalogue with no unlicensed media | English text guidance only | Gym images and GIFs are excluded until Keepfit has original or separately licensed assets. |

## Known Issues / Follow-Up

| Issue | Severity | Action |
