## Summary

Keepfit now provides a focused, resilient active-workout flow. Prior values are
editable or repeatable in one tap, successful sets start the configured timer,
session-only adaptations protect plans and logged work, completion feedback is
optional, and local progression advice is small and explained.

## Changelog

- Added Room schema 8 target snapshots, session variant, energy, and difficulty
  fields with explicit migration and exported schema.
- Added transactional active-session set append, repeat, substitution, minimum
  conversion, and completion commands.
- Loaded ordered sets from the most recent completed exercise performance and
  prefilled the corresponding next set.
- Added deterministic repeat, bounded weight-increase, and bodyweight
  repetition-increase suggestions without mutating templates.
- Started the configured timer only after successful set writes and retained
  its deadline through Android saved state.
- Rebuilt the active screen with a training-progress rail, target context,
  large set actions, reviewed adaptations, and optional 1-5 feedback.
- Updated the application to version `0.4.0` with version code `4`.

## Product Increment Delivered

A user can start or return to a realistic workout, record unchanged sets with
minimal typing, see exactly where the session stands, adapt safely when time or
equipment changes, and finish with transparent next-step guidance entirely
offline.
