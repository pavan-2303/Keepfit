## Summary

A connected user can now ask Coach for a workout-plan draft grounded in the
bundled exercise catalogue, inspect every proposed day and target, and apply
the complete week only through an explicit atomic approval.

## Changelog

- Added a strict `create_workout_plan` provider contract with bounded bundled
  exercise UUIDs and local display-name resolution.
- Added fail-closed validation for unknown or repeated items, invalid targets,
  extra fields, unsafe requests, and provider failures.
- Added a single Room transaction that revalidates and replaces only the
  active profile's weekly plan while retaining exact order and targets.
- Added a compact Coach planning action and vertical schedule review with
  apply, revise, and dismiss controls.
- Routed onboarding's AI choice through the same saved-answer planning flow
  and retained an explicit connect-first OpenRouter disclosure.
- Exposed weekly-schedule and saved-food reviews as preview-only requests.
- Updated architecture, privacy guidance, user guidance, and package metadata
  to version `0.18.0`, code `18`.

## Product Increment Delivered

AI planning is useful without becoming authoritative. The provider can only
choose from the catalogue Keepfit supplies, the current plan is unchanged
during review, and one clear approval either applies the whole validated week
for the active profile or changes nothing.
