## Summary

Keepfit now turns a user's practical constraints into an understandable,
editable starter workout week entirely offline. The user remains in control:
generation is deterministic, previews do not mutate data, and a week is stored
only after explicit confirmation.

## Changelog

- Added repeatable starter-week setup for goal, experience, available days,
  session duration, equipment, and exercises to avoid.
- Added a 16-exercise original offline starter catalogue and deterministic
  session rules with plain-language rationale.
- Added editable preview, explicit apply, and a saved-preferences return flow.
- Added Room schema 6 for journey preferences and generated-template origins.
- Preserved custom templates, prior plans, completed workout history, and media
  when applying or regenerating a starter week.
- Included journey preferences in encrypted backup preview and restore.

## Product Increment Delivered

From Workouts, a new or existing local user can build, review, customize, and
activate a useful one-to-four-day workout week without an account, network
connection, AI model, or paid service.
