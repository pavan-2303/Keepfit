## Summary

Keepfit now supports direct template maintenance from the template detail
screen. A person can rename the template, add exercises, change each
exercise's sets or repetition target, remove an exercise, and safely delete
several unused templates from an explicit selection mode.

## Changelog

- Replaced the full-width template controls with compact, accessible icon
  actions beside the template name.
- Added per-exercise edit and remove actions with a focused prescription
  editor.
- Added catalogue-backed exercise addition without rebuilding the template.
- Added template-list selection mode with select-all or clear and confirmed
  bulk deletion.
- Made bulk deletion all-or-nothing when any selected template is protected.
- Preserved template UUIDs, weekly assignments, existing targets, and workout
  history snapshots.

## Product Increment Delivered

Routine plan maintenance now happens at the object being changed. The template
list stays quiet during normal browsing, selection mode appears only when
requested, and destructive actions remain confirmed and history-safe.
