## Summary

Keepfit now begins with a focused local intake instead of one shallow form.
People can optionally record birth date, height, and starting weight, see age
and BMI context derived on-device, complete a calmer training survey, and then
choose an offline starter week, manual planning, or the existing query-only
Coach without creating an account.

## Changelog

- Split profile setup into identity and optional baseline steps with progress,
  back, skip, validation, privacy, and edit-later guidance.
- Added shared local age and BMI calculations with general-fitness wording.
- Added a Room transaction that creates a profile and, when supplied, exactly
  one profile-owned starting measurement.
- Added birth-date editing to the existing profile editor without making any
  baseline field mandatory.
- Reworked starter setup into seven compact steps while preserving all existing
  deterministic planning inputs and saved choices.
- Collapsed the bundled movement-constraint catalogue by default, with search
  and selected-item visibility available on demand.
- Added explicit routes to offline starter preview, manual Plan, and query-only
  Coach, with no provider requirement for offline or manual use.
- Updated architecture and user guidance and advanced the app to version
  `0.16.0`, version code `16`.

## Product Increment Delivered

A person can complete useful onboarding entirely offline, omit body data they
do not want to record, and leave setup through the planning path that matches
their intent. Starting weight becomes ordinary Progress history rather than a
separate onboarding-only value, while AI remains optional and accurately
described.

## Deviations from Original Plan

| Item | Planned | Actual | Reason |
|---|---|---|---|
| Profile intake length | Focused progressive questions | Two profile steps followed by the existing seven training steps | This separates personal identity and baseline data from planning preferences while keeping every screen purposeful. |
| Gender or calculation sex | Consider as part of deeper onboarding | Not collected | Neither BMI nor the deterministic v0.16 planner uses it, so collection would add sensitive data without visible value. |
| AI planning exit | Optional AI-assisted path | Query-only Coach destination | Structured plan generation remains deliberately deferred until v0.18 validation and approval controls exist. |
