## Outcome

Exercise details now behave like a focused movement sheet rather than a text
dump. The repeated dataset/MIT line has been removed from every exercise while
the full upstream terms remain packaged in the APK and a compact About entry
reveals catalogue details on demand.

Keepfit source code is now Apache-2.0. Future media is restricted only when an
asset manifest or adjacent notice explicitly applies the Keepfit Restricted
Media License. User imports retain their owner's rights, third-party material
retains its own licence, and current code-native movement figures remain
Apache-2.0.

## Decisions

| Decision | Reason |
|---|---|
| Retain the pinned MIT catalogue | Paraphrasing 1,316 records would not automatically erase provenance obligations and would introduce unnecessary quality and exercise-safety risk. |
| Keep one expandable in-app disclosure | It preserves accessible attribution without making legal prose part of the workout-reading path. |
| Package root legal documents through a generated asset task | Repository and binary distributions now receive the same authoritative files without hand-maintained copies. |
| Restrict only explicitly marked media | Apache remains unambiguous for code and current code-native figures; future owned media can use a separate grant without relicensing unrelated files. |
