## Summary

Keepfit now turns the most recently completed week into a calm, deterministic
offline review. It highlights real progress or a return after interruption and
offers at most two small, editable changes for the coming week. Nothing changes
until the user approves one proposal.

## Changelog

- Added Room schema 9 for one idempotent review outcome per completed ISO week,
  with explicit migration, exported schema, and encrypted-backup coverage.
- Added deterministic completion, performance, return, optional nutrition and
  step-signal, encouragement, and proposal-selection rules.
- Added a dedicated `feature:review` module and an app-level activity adapter
  that keeps Health Connect optional and never requests access on screen open.
- Added read-only previews and explicit approve, edit, dismiss, pause, and
  resume behavior.
- Applied approved changes as one dated occurrence in the coming week while
  protecting reusable templates, recurring plans, and workout history.
- Added a Today review card and a focused review screen with a seven-day
  evidence ribbon and plain-language proposal reasoning.
- Updated the application to version `0.5.0` with version code `5`.

## Product Increment Delivered

A user can review last week in about two minutes, understand what went well,
consider one practical adjustment, edit its date when applicable, and either
apply or dismiss it without AI, an account, internet access, or hidden plan
mutation.
