## Summary

Keepfit now supports several isolated local profiles without introducing an
account or backend. A compact avatar menu adds, switches, edits, and archives
profiles; Room queries and mutations enforce ownership below the UI; ordinary
preferences follow the selected profile; and exercise and food reference
libraries remain intentionally shared.

## Changelog

- Added Room schema 11 with profile ownership for workout, nutrition, and
  weekly-review roots plus a migration that assigns existing personal data to
  the original profile.
- Added observable active-profile persistence and profile-namespaced ordinary
  settings while keeping credential-recovery consent device-level.
- Scoped workout, nutrition, review, goals, transformation, starter-plan, and
  assistant-summary repositories to the active profile.
- Added a compact app-bar profile menu with add, switch, edit, archive, final
  profile protection, and accessibility semantics.
- Upgraded encrypted-backup format to preserve every profile, each profile's
  settings, and the active profile while retaining format-1 restore support.
- Updated the app to version `0.12.0` with version code `12`.

## Product Increment Delivered

Several people can use one Keepfit installation and switch instantly without
mixing their plans, logs, goals, reviews, measurements, transformations, or
preferences. Shared offline exercise and food catalogues remain reusable, and
the complete local profile state is covered by encrypted export and restore.

|---|---|---|---|
| Profile menu location | Add, switch, edit, and archive from the app bar, including the Coach header | The shared five-tab app bar exposes the menu; Coach retains its existing focused header and Settings shortcut | Avoided duplicating stateful profile controls inside the specialized chat header; profile switching remains one tab away. |
