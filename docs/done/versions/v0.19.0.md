## Summary

Keepfit now uses one restrained training-field-guide hierarchy across its core
journeys, with short purposeful transitions, success-only workout haptics, and
a backed-up device-level reduced-motion preference.

## Changelog

- Refined the green, orange, paper, slate, and ink theme, typography, shapes,
  surfaces, and spacing without remote fonts, gradients, or decorative media.
- Added reusable pace-card, section-header, status-mark, and motion-policy
  primitives in `core:designsystem`.
- Applied the hierarchy to the shell, Today, Plan, active workouts, Coach,
  Settings, and the Appearance/accessibility flow.
- Added short destination and Today-state fades plus completion haptics only
  after a workout reaches the completed state.
- Added a device-level `Reduce motion` control and included it in encrypted
  backup format v3 while retaining reads of older formats.
- Added compact-width, 200% text, layout-order, preference, shell-state, and
  backup tests.
- Updated architecture, user guidance, and Android metadata to version
  `0.19.0`, code `19`.

## Product Increment Delivered

Daily decisions now read as a calm training docket: one primary action, a clear
pace line, strong sentence-case hierarchy, and quieter supporting information.
Users who prefer less motion retain every state and action without nonessential
transitions.

## Performance Evidence

The post-install cold launch completed in 2,064 ms. A controlled Today-to-Plan
round trip on the known-slow AVD reported 42.86% janky frames at normal motion
and 33.33% with reduced motion. Navigation remained functional, and reduced
motion improved the sample, but these absolute figures are not a substitute for
profiling on the owner's physical phone.
