# Roadmap

This roadmap captures future themes and sequencing only.

## Rules

- Do not assign speculative semver numbers here
- Use this file for themes, dependencies, and ordering
- Slice work into real sprint versions only when scope is clear

## Current Themes

1. Make planning, daily execution, and recovery from missed days effortless.
2. Turn logged data into a short weekly review and transparent plan changes.
3. Motivate through consistency, progress, and returning after interruptions.
4. Replace the transient online catalogue prototype with a pinned, audited
   offline metadata dataset and separately owned or licensed guidance media.
5. Validate an optional, user-funded OpenRouter coach without weakening the
   offline product or exposing manually copied API keys.
6. Reorganize onboarding, navigation, visual hierarchy, and daily paths using
   the [fitness app UX benchmark](references/fitness-app-ux-benchmark.md).
7. Consider a low-cost paid model only after the assistant workflow passes a
   repeatable quality, privacy, reliability, and safety evaluation.
8. Protect local progress across reinstall, then support several completely
   isolated local profiles without introducing a Keepfit account or backend.
9. Replace the transient catalogue dependency with an audited build-time
   offline dataset and separately owned or licensed guidance media.
10. Expand transformation tracking from four fixed angles to selectable pose
    sets with original reference artwork and privacy-preserving photo handling.
11. Add durable profile-scoped Coach conversations, named communication styles,
    optional validated plan creation, and purposeful motion after the core
    flows are stable.

Detailed discovery for these themes is tracked in the
[Practical Fitness Journey and Optional AI Coach](backlog/items/practical-fitness-journey-and-ai-coach.md)
initiative.

Approved follow-on discovery and sequencing is tracked in the
[Durable Personalized Fitness Companion](backlog/items/durable-personalized-fitness-companion.md)
initiative. It begins only after v0.10.0 closes.

Quick-start planning, decisive daily execution, low-friction workouts, the
offline weekly review, sustainable nutrition, and exercise guidance are
complete through the pre-beta
[v0.9.0 - Bounded Coaching Workflows](done/versions/v0.9.0.md). Journey UX
reorganization is next as
[v0.10.0 - Guided Journey and Interface Reorganization](versions/v0.10.0.md)
and is now in progress.

## Delivery Order

1. Quick-start planning and a decisive, resilient Today experience.
2. Faster workout execution, local progression, weekly review, and motivation.
3. Sustainable nutrition depths and shortcuts.
4. Owned offline exercise guidance and a transient view-only online prototype.
5. User-authorized OpenRouter access and bounded coaching workflows.
6. Guided onboarding, practical navigation, information hierarchy, and visual
   cleanup based on observed fitness-app patterns.
7. Correct Coach rendering and establish reinstall-safe recovery.
8. Add complete local-profile isolation before profile-owned feature growth.
9. Expand transformation poses and replace the runtime catalogue with audited
   offline content plus a rights-aware media pipeline.
10. Deepen onboarding and manual planning, then persist named Coach histories.
11. Enable validated AI plan drafts only after profiles, catalogue identifiers,
    onboarding, and conversation memory are stable.
12. Apply intentional motion, visual identity, accessibility, performance, and
    private-beta hardening.

Each phase is decomposed into sprint-sized delivery slices in the linked
initiative. Semver is assigned only when the next slice is approved as an
execution-ready version specification.
