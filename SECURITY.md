# Security Policy

## Supported Versions

Security fixes target the latest published Keepfit release. Older sideloaded
builds may not receive fixes.

## Reporting a Vulnerability

Use the repository's **Security > Report a vulnerability** form to submit a
private report. Do not open a public issue containing exploit details, API
tokens, signing information, personal fitness data, or private media.

If private vulnerability reporting is unavailable, open a minimal public issue
asking the maintainer for a private contact channel without including the
sensitive details.

Include:

- the affected version and Android version;
- reproducible steps or a proof of concept;
- the expected impact;
- any suggested mitigation.

The maintainer will acknowledge and assess reports on a best-effort basis.
Please allow a reasonable remediation window before public disclosure.

## Important Boundaries

Keepfit stores health and fitness records locally. Reports involving backup
encryption, credential handling, profile isolation, media privacy, or release
signing are especially important. General fitness or medical disagreements are
not security vulnerabilities.
